## Ограничения и следующие шаги

- Восстановление — на уровне категории: незавершённая категория собирается
  с первой страницы в новом raw-каталоге. Историческая цена за пропущенный
  день не восстанавливается; новое время явно записано в collectedAt.
- Нет SQL, расписания, API и аналитического экспорта.
- Не проверены каталоги всех форматов Магнита. Перед массовым запуском нужен
  выбранный список подходящих магазинов и категорий; готовность очереди
  не означает готовность опросить все 669 записей справочника.
- Защита одновременного запуска опирается на блокировку отдельного профиля
  Chrome: не запускайте discovery и товарный сборщик Магнита одновременно.
- Не редактировались store-discovery и scheduler Пятёрочки. VPN и системные
  настройки не менялись. Выключение ноутбука сегодня не назначалось.

Дальше: определить небольшой рабочий набор магазинов и категорий, проверить
его через dry-run, затем выполнить ограниченный пакетный сбор. SQL можно
продолжать откладывать.

## Второй этап 3 сентября: терминал и подготовка расписания

По новому решению пользователя БД будет локальной PostgreSQL; подключение
по-прежнему отложено, резервное копирование пользователь планирует отдельно.
Решение отражено в PROJECT_CONTEXT.md и README.

Добавлено:

  паре или по файлам, preview плана, подтверждение ДА, resume/retry-failed,
  просмотр состояний, подготовка профилей. Ошибки возвращают в меню.
- `pnpm run menu` (также `node --import tsx src/menu.ts`).
- Dry-run Пятёрочки без запросов и записи состояния.
- `src/daily.ts` и `src/operations/`: ежедневная команда, последовательные
  сети, предварительная проверка всех файлов, явный --execute, блокировка
  одновременного daily и запрет второго запуска в тот же день.
- Пример config/daily.example.json, инструкции RUN_TERMINAL.md и RUN_DAILY.md.
- Защита Пятёрочки от продолжения очереди при 401/403/429/Retry-After;
  исправление выбора только failed, paused для незавершённых задач и
  атомарная запись состояния. Состояние загружается после захвата профиля.
- Таймаут запроса Пятёрочки 30 секунд; ограничения сервера не игнорируются.
- Локальные файлы списков и daily config добавлены в .gitignore.

Проверки: меню реально открыто в терминале, просмотрены существующие
состояния обеих сетей, выполнен выход. Dry-run Пятёрочки показал одну пару
без открытия браузера. Daily CLI проверяется отдельным процессом в default
preview-режиме на временных тестовых файлах; execute проверен на mock-
