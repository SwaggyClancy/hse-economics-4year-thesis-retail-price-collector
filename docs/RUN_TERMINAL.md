# Меню в терминале

```powershell
pnpm run menu
```

Без pnpm, используя установленные зависимости:

```powershell
.\node_modules\.bin\tsx.cmd src/menu.ts
```

Открывается обычное текстовое меню. Введите номер и нажмите Enter.

1. Проверка плана без запуска.
2. Сбор Пятёрочки.
3. Сбор Магнита.
4. Продолжение прерванного запуска.
5. Повтор только неудачных заданий.
6. Состояния запусков и пути файлов.
7. Инструкция по расписанию (не активирует его).
8. Настройка отдельного профиля браузера.
9. Проверка качества локальных JSON и сохранение отчёта (без сети).
10. Повторная обработка raw-каталога без сети (запись только после подтверждения).
0. Выход.

Для сбора выбирается одна пара магазин/категория либо два файла кодов.
Поддерживаются TXT и JSON. Перед запуском меню показывает число магазинов,
категорий и заданий, затем просит ввести `ДА`. Enter отменяет запуск.
Предварительная проверка не обращается к сайтам и не записывает состояние.

Сбор запускается в headless-режиме. Для подготовки профиля используйте пункт 8:
это откроет видимый браузер с профилем сети, не основной профиль пользователя.
Не запускайте несколько сборщиков или discovery одновременно на одном профиле.

Восстановление требует пути к файлу `data/state/{chain}/RUN.json`, а не к
исходному ответу API. Файлы состояний можно увидеть через пункт 6.
При ошибке меню показывает сообщение и остаётся открытым. Журналы самих
сборщиков находятся в logs; результаты — в data/normalized и data/raw.

Не используйте меню для автоматического расписания: оно требует ввода.
Для этого предусмотрен отдельный daily runner (RUN_DAILY.md).
Меню не создаёт БД, не меняет VPN, не выключает компьютер и не удаляет данные.
