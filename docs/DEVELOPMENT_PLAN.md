# План разработки

## Этап 0. Подготовка

- Создать Git-репозиторий.
- Положить старые скрипты в `old-scripts/`.
- Положить примеры JSON в `samples/`.
- Зафиксировать список магазинов и категорий.
- Подготовить `.env` и конфигурацию.

## Этап 0.5. Справочник магазинов

- Инициализировать коды и адреса отдельно для каждой сети и города.
- Определить административные и муниципальные районы.
- Сохранить первый версионируемый снимок справочника.
- Добавить сравнение повторного снимка: новые, изменившиеся, не обнаруженные.
- Не удалять прежние коды автоматически.
- Передавать подтверждённый справочник планировщику товарных заданий.

## Этап 1. Минимальный сборщик Пятёрочки

Цель:

```text
1 магазин
+ 1 категория
+ Playwright
+ вся пагинация
+ исходный JSON
```

Критерии готовности:

- профиль сохраняется между запусками;
- запросы выполняются из контекста страницы;
- все страницы категории собраны;
- ошибки логируются;
- файл создаётся автоматически.

## Этап 2. Нормализация Пятёрочки

- Перенести логику из старого конвертера.
- Создать общие TypeScript-типы.
- Добавить тесты на пример JSON.

## Этап 3. PostgreSQL

- Добавить миграции.
- Создать таблицы запусков, задач, товаров и снимков.
- Сохранить один результат Пятёрочки.

## Этап 4. Магнит

- Реализовать отдельный collector.
- Реализовать пагинацию POST-запросов.
- Добавить нормализатор.
- Сохранить данные в те же таблицы.

## Этап 5. Очередь задач

- Создать задания магазин × категория.
- Добавить статусы.
- Добавить продолжение после перезапуска.
- Добавить повтор только неудачных задач.

## Этап 6. Ограниченная параллельность

Начать с:

```text
Пятёрочка: 2
Магнит: 2
```

Измерять:

- время полного обхода;
- долю ошибок;
- частоту 429/403/503;
- стабильность браузера;
- нагрузку на компьютер.

## Этап 7. Расписание

- запуск по времени;
- защита от двойного запуска;
- ожидание следующего цикла;
- ручной запуск;
- остановка.

## Этап 8. Управление

- локальный API;
- статус текущего запуска;
- список ошибок;
- повтор задач;
- простая веб-панель.
- отдельная вкладка инициализации и обновления справочника магазинов;
- просмотр изменений перед применением к рабочему справочнику;
- ручной запуск примерно раз в полгода, без привязки к ежедневному расписанию.

## Этап 9. Экспорт

- Excel;
- CSV;
- отчёт по запуску;
- агрегированная статистика.

## Этап 10. Упаковка

- понятный запуск на Windows;
- автозапуск;
- конфигурация через файл или интерфейс;
- резервное копирование;
- инструкция по восстановлению.
