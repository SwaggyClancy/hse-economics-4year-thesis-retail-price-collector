# Примеры данных

Сюда положить реальные примеры ответов API без чувствительных данных.

```text
samples/
├── pyaterochka/
│   └── sample.json
└── magnit/
    └── sample.json
```

Желательно, чтобы каждый пример содержал:

- несколько товаров;
- обычную цену;
- скидочную цену;
- товар без скидки;
- недоступный товар, если такой встречается;
- рейтинги и единицы измерения, если они присутствуют.

Эти файлы будут использоваться для тестов нормализации.
