# Участие в проекте

Репозиторий ведётся как индивидуальная дипломная работа SwaggyClancy.
Публичные pull request сейчас не принимаются, чтобы сохранять однозначное
авторство исследования. Воспроизводимые сообщения об ошибках можно передавать
через GitHub Issues после публикации репозитория.

Не отправляйте cookies, токены, пароли, строки подключения, персональные
данные, браузерные профили и реальные большие выгрузки магазинов.
