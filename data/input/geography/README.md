# Географические границы

Файлы в этой папке используются для генерации точек Пятёрочки и локального
распределения магазинов по районам.

Источник: участники OpenStreetMap, данные доступны по лицензии ODbL:
https://www.openstreetmap.org/copyright

Дата получения исходных данных: 9 сентября 2026 года.

## Файлы

- `moscow-boundary.geojson` — административная граница Москвы, OSM relation
  `102269`;
- `saint-petersburg-boundary.geojson` — административная граница
  Санкт-Петербурга, OSM relation `337422`;
- `moscow-okrugs.geojson` — 12 административных округов Москвы;
- `moscow-districts.geojson` — 132 района Москвы;
- `saint-petersburg-districts.geojson` — 18 административных районов;
- `saint-petersburg-municipalities.geojson` — 111 внутригородских
  муниципальных образований.

Границы городов получены единичными поисковыми запросами Nominatim с
`polygon_geojson=1`. Районные границы получены одним набором через Overpass и
преобразованы локально модулем `src/store-discovery/geography/overpass.ts`.
Исходные ответы сервисов находятся в локальной подпапке `source/` и не
коммитятся, поскольку производные GeoJSON уже содержат необходимые границы.

При публикации карт, таблиц или аналитики, основанной на этих полигонах,
необходимо сохранять атрибуцию OpenStreetMap.
